# Предложения — SystemBar Indicator

## Архитектурные предложения

### 1. Выбор подхода к рендерингу
**Рекомендация:** Использовать гибридный подход — WinUI 3 для окна настроек, GDI+ для оверлея на панели задач.
- GDI+ даёт минимальное потребление CPU (~0.1%)
- WinUI 3 обеспечивает современный UI для настроек
- Это подход kil0bit System Monitor, доказавший эффективность

### 2. Источник данных о температурах
**Рекомендация:** Использовать **LibreHardwareMonitor** (форк OpenHardwareMonitor).
- Поддерживает CPU, GPU, motherboard, диски
- Активно поддерживается сообществом
- Не требует установки драйверов
- Альтернатива: WMI (менее точный, но без зависимостей)

### 3. Позиционирование на панели задач
**Рекомендация:** Использовать `SHAppBarMessage` для определения позиции и размера панели задач.
- Автоматическое определение ориентации (верх/низ/лево/право)
- Корректная работа с несколькими мониторами
- Адаптация при изменении размера панели

## UX предложения

### 4. Режимы отображения
Предлагаю 3 режима:
- **Компактный** — только иконки + проценты (CPU🔥45% RAM 62%)
- **Полный** — иконки + значения + температуры
- **Минимальный** — только цветные индикаторы (точки)

### 5. Цветовая индикация нагрузки
- 🟢 Зелёный: 0-60% — норма
- 🟡 Жёлтый: 60-80% — внимание
- 🟠 Оранжевый: 80-90% — высокая нагрузка
- 🔴 Красный: 90%+ — критическая нагрузка

### 6. Умное скрытие
- Автоматическое скрытие при полноэкранных приложениях (игры, видео)
- Скрытие при запуске Диспетчера задач
- Показать при наведении мыши на край панели задач

## Технические предложения

### 7. Система плагинов
Создать интерфейс `ISensor` для легкого добавления новых сенсоров:
```csharp
public interface ISensor
{
    string Name { get; }
    string Icon { get; }
    SensorData Read();
    bool IsAvailable { get; }
}
```

### 8. Конфигурация через JSON
Хранить настройки в `%APPDATA%/SystemBarIndicator/config.json`:
- Включённые сенсоры
- Цвета и темы
- Интервал обновления
- Позиция и размер

### 9. Логирование
Использовать **Serilog** для структурированного логирования:
- Лог файл в `%LOCALAPPDATA%/SystemBarIndicator/logs/`
- Ротация логов (макс 10 МБ)
- Уровни: Error, Warning, Info

### 11. Цифровая подпись
- Подписать код сертификатом для Windows SmartScreen

## Альтернативные технологические стеки

| Стек | Плюсы | Минусы |
|------|-------|--------|
| **C# + WinUI 3** (рекомендуемый) | Нативный, быстрый, современный | Привязка к Windows |
| C++ + Win32 | Максимальная производительность | Сложнее разработка |
| Rust + egui | Безопасность, скорость | Меньше библиотек для Windows API |
| Electron | Быстрая разработка | Высокое потребление RAM |
| Python + PyQt | Простота | Медленнее, нужна упаковка |

**Вывод:** C# + WinUI 3 — оптимальный баланс скорости разработки, производительности и нативности.
